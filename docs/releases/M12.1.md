# M12.1 — Execution Integration & Governance Closure

_M12 Frozen Baseline — Released 2026-08-01_

## Added

- **Execution Platform Integration** — `ExecutionIntegrationService` +
  `ExecutionWorker` connect the GUI to `ExecutionPipeline` +
  `RenameExecutionEngine`.  Execution, rollback, and observability now
  use the M11/M12 platform.
- **RollbackPlugin Integration** — `MainWindow._on_undo()` uses
  `RollbackPlugin.rollback()` (LIFO undo with `RollbackResult`),
  replacing the pre-M12 `UndoEngine`.
- **Execution Trace Integration** — Every execution run produces an
  `ExecutionTrace` + `ExecutionMetrics`.
- **Runtime Governance Documentation** — 7 new documents establishing
  architecture baseline, decision record, normative contract, and
  maintenance inventory:

| Document | Type |
|---|---|
| [Runtime Architecture](../architecture/runtime_architecture.md) | Architecture documentation |
| [ADR-007](../architecture/adr/007-execution-integration.md) | Architecture Decision Record |
| [Runtime Contract](../contracts/execution_integration.md) | Normative contract |
| [Legacy Inventory](../maintenance/legacy_inventory.md) | Maintenance inventory |
| [Dependency Audit](../maintenance/dependency_audit.md) | Maintenance audit |
| [Known Limitations](../maintenance/known_limitations.md) | Maintenance documentation |
| [Maintenance Summary](../maintenance/maintenance_summary.md) | Maintenance overview |

## Changed

- **GUI Execution Backend** — `MainWindow._on_rename()` now uses
  `ExecutionWorker` → `ExecutionIntegrationService` →
  `ExecutionPipeline.run()` instead of `RenameWorker` → `RenameEngine.rename()`.
- **Runtime Integration Architecture** — New Integration Layer
  (`ExecutionIntegrationService`) between Planning Layer and Execution
  Layer.  Classified as Thin Integration Layer (A/B/C class only).

## Unchanged

- **RenamePlanEngine** — Continues as Planning SSOT (RenamePlan generation,
  RenamePolicy application, validation, conflict detection).
- **Preview** — `PreviewEngine.generate_preview()` unchanged.
- **Scan** — `Scanner` + `ScanWorker` unchanged.
- **Planning Layer** — Full planning pipeline intact.
- **OperationLogger** — Still active for cross-run log display.
- **All 9 Capability Plugins** — Unchanged.
- **All Frozen Modules** — 11/11 CLEAN (zero modifications).
